# Playbook: 初始化必需的酒店与航班依赖

## 目的

TourMind 酒店 Skill 与 Kiwi.com MCP 是 Travel Journal Creator 的必需安装项。安装或首次初始化时，由宿主 Agent 主动检查并安装缺失项、验证可发现性。默认无感完成，不向用户增加“要不要装酒店/航班能力”的选择题；不能只复制主 Skill 就宣布安装完成。

## 前提条件

- 当前任务是安装、初始化或使用 Travel Journal Creator；只阅读文档、审查代码或排查接口时不触发安装。
- 使用宿主实际提供的 Skill 安装工具、目录和 MCP 管理接口；目录未知先检查客户端设置，不假定所有宿主都使用 Codex 路径。
- 官方来源为 [TourMind 仓库](https://github.com/tourmind-com/Tourmind-Booking-Skills)，Kiwi 地址为 `https://mcp.kiwi.com`。
- 安装 Travel Journal Creator 的任务包含这两项必需依赖。沿用已有授权，不重复确认；宿主强制的权限批准、客户端交互或用户明确禁止安装时仍须遵守，不能用本文件绕过。

## 步骤

1. 初始化一开始先读取当前宿主已暴露的 Skill 与工具，必要时调用发现工具搜索。TourMind 须能读取 `tourmind-booking/SKILL.md` 和配套参数指南；Kiwi 须能发现 `search-flight`（宿主可能显示为 `search_flight`）。已可用则复用，不重新下载、不更新现有版本、不重复添加同地址连接。保留本会话检查结果；宿主变化或实际调用提示缺失时重新检查，不每轮执行安装。
2. TourMind 确认缺失后，在当前宿主技能目录安装完整官方仓库。优先使用宿主安装工具；Codex 提供 skill-installer 时读取其说明并直接调用现有安装脚本，仓库参数为 `--repo tourmind-com/Tourmind-Booking-Skills --path . --name tourmind-booking`，必要时用 `--dest` 指定已确认目录。没有安装工具但有 Git 时执行以下命令，替换已确认目录占位符；先确认目标不存在。已有但不完整的目录视为待修复，不能覆盖未知文件或凭证。

   ```bash
   git clone https://github.com/tourmind-com/Tourmind-Booking-Skills.git "<客户端技能目录>/tourmind-booking"
   ```

3. Kiwi 确认缺失后，直接调用宿主远程 MCP 添加接口：名称 `kiwi-com-flight-search`，URL `https://mcp.kiwi.com`，传输 `streamable_http`，无需 API Key。Codex CLI 可用时先检查现有连接（内部处理列表，不输出其他连接的配置或凭证），只有不存在同地址连接且名称未被占用时执行：

   ```bash
   codex mcp add kiwi-com-flight-search --url https://mcp.kiwi.com
   ```

   已存在同地址连接则复用；同名指向不同地址则报告冲突，不能覆盖。宿主没有添加接口或需要用户在 UI 点击时，合并成一次最短操作提示，给出准确参数，不输出整套安装教程。
4. 安装后触发宿主支持的发现刷新或热加载，再检查两项能力。无法热加载时，只提示一次重载或开启新对话。仅目录存在、配置保存、`agents/openai.yaml` 声明或 MCP URL 可达，都不代表当前会话已能使用。
5. 两项均可发现才标记初始化完成，随后直接承接用户旅行需求，不逐项播报工具安装过程。用户专门要求安装时，用一句话确认主 Skill 与机酒能力已就绪。配置待重载、权限受限、网络失败或客户端不支持时，保留初始化未完成状态并说明唯一必要下一步；已完成项不回滚，也不在下一轮重复安装。

## 判断标准

- 必需安装与按需查询分开：即使用户暂时只规划路线，也准备这两项依赖；不因依赖准备提前索取日期、人数、酒店偏好，不自动搜索、生成或预订。
- 宿主发现列表不完整 → 先搜索或刷新；安装文件可读但当前会话未发现 → 标记待加载，不能误报未安装。
- TourMind 通过 HTTPS 查询，不需要额外酒店 MCP。按实际安装版本的官方契约选择公开个人或已授权通道；可公开查询时不要求登录或 Token，不为初始化读取或打印已有凭证。
- 命令或网络失败 → 保留完整错误供开发排查，正常用户仅说明影响与下一步；不无限重试、不擅自换源。未知文件冲突或宿主强制权限只能按真实限制处理。
- 用户明确拒绝安装或客户端无法完成 → 尊重限制，标记必需依赖尚未就绪，不能称为完整安装。已有路线内容可以继续整理，不将恢复依赖变成旅行日期或生成的额外确认关卡。
- 安装没有通用的 SKILL.md 执行钩子：流程由宿主安装 Agent 或首次加载 Skill 的 Agent 执行。不能声称导入 ZIP 就会自行执行命令或静默改动任意客户端配置。
- 下单、支付、取消、上传照片和创建行程不属于初始化动作。

## 验证

- TourMind 入口、参数指南与配套文件已安装且可被宿主发现；Kiwi 的 `search-flight` 已暴露给当前 Agent。
- 两项就绪才确认完整安装；配置成功但需重载时明确保留待重载状态，不声称实时查询已成功。
- 已就绪环境再次初始化不创建新目录、重复连接或覆盖配置。
- 缺失项自动安装；必须用户操作时合并提示，保留旅行需求，恢复后继续原任务。
